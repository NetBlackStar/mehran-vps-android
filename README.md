# مدیریت VPS مهران‌هاست

یک منطق مشترک (`www/core.js` + `www/index.html`) که هم در Termux (نسخه وب) و هم در اندروید (APK) اجرا می‌شود.

## امکانات
- کلید API (پیست یا انتخاب از فایل) ← انتخاب موقعیت/پلن/سیستم‌عامل ← ساخت سرور با رمز روت ← نمایش آی‌پی
- نصب AmneziaWG روی سرور از طریق SSH و نمایش/کپی/اشتراک کانفیگ کلاینت
- حذف سرور
- **پیش‌فرض‌ها:** با تیک «ذخیره به‌عنوان پیش‌فرض»، موقعیت، پلن، سیستم‌عامل، **رمز روت و نام سرور** ذخیره می‌شوند و دفعه بعد خودکار پر می‌شوند.
  (رمز روت روی همان دستگاه ذخیره می‌شود: در اندروید در حافظه خصوصی برنامه، در Termux در localStorage مرورگر.)

## ساخت APK
APK را باید با Android SDK ساخت (در محیطی که این پروژه را ساختم Android SDK در دسترس نبود). سه راه:

### راه ۱: GitHub Actions (ساده‌ترین، بدون نصب چیزی)
1. یک مخزن خصوصی در GitHub بسازید و محتوای همین پوشه را در آن push کنید.
2. به تب Actions بروید ← «Build APK» ← Run workflow (یا بعد از push خودکار اجرا می‌شود).
3. بعد از چند دقیقه APK به‌صورت خودکار در بخش Releases همین مخزن منتشر می‌شود (`vps-manager.apk`)؛ از همان‌جا دانلود و نصب کنید.

### راه ۲: Android Studio
پوشه `android` را باز کنید ← Build ← Build APK(s).

### راه ۳: خط فرمان (با JDK 17 و Android SDK)
    cd android && ./gradlew assembleDebug
خروجی: `android/app/build/outputs/apk/debug/app-debug.apk`

## اجرای نسخه وب در Termux
    pkg install python openssh sshpass
    python app.py
سپس http://127.0.0.1:8080 را در مرورگر باز کنید.

## نکات
- هنگام ساخت سرور و نصب AmneziaWG برنامه را باز و صفحه را روشن نگه دارید (چند دقیقه طول می‌کشد).
- کلید API باید دسترسی‌های `read`، `billing` (ساخت) و `destructive` (حذف) داشته باشد؛ اگر کلید آی‌پی مجاز دارد، آی‌پی گوشی باید در فهرست باشد.
- نصب AmneziaWG فرض می‌کند سیستم‌عامل Ubuntu است.
- اتصال SSH: اول با رمز روت وصل می‌شود؛ اگر نشد، با کلید SSH ذخیره‌شده. وقتی ورود با رمز موفق باشد، برنامه با `ssh-copy-id` یک کلید (که فقط بار اول ساخته می‌شود؛ در اندروید در حافظه خصوصی برنامه، در Termux در `~/.ssh/vpsm_ed25519`) در `/root/.ssh/authorized_keys` سرور قرار می‌دهد تا برای دفعات بعد قابل استفاده باشد.
- برنامه دیگر `openssh-server` نصب نمی‌کند و `sshd_config` را تغییر نمی‌دهد؛ سرور باید از قبل SSH روی پورت ۲۲ داشته باشد (ایمیج‌های Ubuntu هتزنر دارند).
- **لاگ SSH:** دکمه «دانلود لاگ SSH» جزئیات هر تلاش اتصال (روش رمز/کلید، کد خروج، خطاها و لاگ دیباگ کلاینت SSH) را در یک فایل `ssh-log.txt` ذخیره می‌کند (در اندروید با انتخاب محل ذخیره؛ در وب دانلود مرورگر). رمز در لاگ نوشته نمی‌شود.
- در Termux این بسته‌ها لازم است: `pkg install openssh sshpass`.
